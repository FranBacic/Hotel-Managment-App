# Hotel Management Application

A full-stack web application for managing a hotel, its rooms, reservations, users, and additional hotel services.

The application provides different functionality depending on the user's role, with separate access permissions for regular users and hotel staff.

## Technologies

### Frontend
- **React**
- **JavaScript**
- **Bootstrap**

### Backend
- **Node.js**
- **Express.js**

### Database
- **MongoDB**

## User Roles

The application supports three main types of users:

### Unregistered User

Users who are not logged in can:

- View the hotel homepage
- Browse available rooms
- View room details and reviews
- View additional information about the hotel
- Browse the hotel gallery

Unregistered users cannot make reservations.

### Registered User

After creating an account and providing their personal information, registered users can:

- Log in to their account
- View their profile
- Browse available rooms
- Make room reservations
- View their reservations
- Access their personal account information

### Administrator

Administrators have access to hotel management functionality and can manage different aspects of the application.

Administrators can:

- Manage hotel information displayed on the website
- Manage users
- Manage reservations
- Manage rooms
- Manage massage services
- View hotel statistics

## Administrator Roles

The application provides three different administrator roles with different access permissions.

### Admin

The administrator has full access to the hotel management system and can manage all available data and functionality.

### Receptionist

The receptionist has access to functionality relevant to front-desk operations.


### Masseur

The masseur has access to functionality relevant to massage services and can view and manage the data required for their work.

This role-based approach ensures that each administrator can only access the functionality relevant to their responsibilities.

## Main Features

- User registration and authentication
- Role-based access control
- Hotel information management
- Room browsing and management
- Room reviews
- Room reservations
- User profile management
- Reservation management
- Hotel gallery
- Massage service management
- User management
- Administrator management
- Hotel statistics
- Different access permissions based on user roles
- Responsive user interface using Bootstrap
